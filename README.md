# Azeroth Auto Pilot — Legion 7.3.5

Azeroth Auto Pilot (AAP) is a leveling and quest-route addon for **World of Warcraft: Legion 7.3.5** (`Interface: 70300`). It provides step-by-step quest guidance, waypoint arrows, quest objectives, map pins, and leveling routes from level 20 through level 110.

## Project goal

Redeveloping AAP as a dependable, Legion 7.3.5-compatible leveling and quest-route addon while preserving clear step-by-step guidance.

## Install

1. Download or clone the [`legion-7.3.5-port`](https://github.com/Peaap/aap/tree/legion-7.3.5-port) branch.
2. Copy the included AAP folders into your Legion client's `Interface\AddOns\` folder.
3. Start the game and enable the AAP addons from the AddOns menu.

Keep the folder names and layout unchanged. `AAP-Core` is required and must be installed together with any route packages you want to use.

## Included route packages

| Addon | Level range |
| --- | --- |
| `AAP-Core` | Required core addon |
| `AAP-Vanilla` | 20–60 |
| `AAP-TBC-WotLK` | 60–80 |
| `AAP-Cata-MoP` | 80–90 |
| `AAP-WoD` | 90–100 |
| `AAP-Legion` | 100–110 |

This branch is specifically packaged for Legion 7.3.5 and uses the bundled HereBeDragons 1.0 map libraries.
